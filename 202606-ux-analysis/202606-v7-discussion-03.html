v6漸層填滿 CTA 大按鈕 → v7文字連結「進入數智空間 ›」

v6固定 3 條通用痛點，選職能後只有 highlight 效果 → v7痛點文字隨職能切換

P2
職能 badge 改為可切換入口
左上角從靜態的「你是採購 → 選一個你想體驗的場景」橋接列，改成醒目的青綠色 badge「採購」＋旁邊「切換其他職能 ›」連結。使用者可以在 P2 就地切換職能，不需要退回 P1。

05
P2
新增職能描述文字區塊
職能 badge 下方加入該職能的簡短描述段落，以及「職能的常見工作場景類型」標題。讓使用者在 P2 就能了解這個職能是做什麼的，補充 P1 跳過的脈絡說明。
v6無職能描述，直接顯示場景卡片 → v7職能描述段落 ＋ 常見場景類型標題
06
P2
場景分類 filter 改為膠囊 Tab
從現在的小型 chip 切換列，改成較大的「全部 ╱ 生產管理 ╱ 採購與供應鏈」膠囊 tab。「全部」預設選中（青綠色填滿），未選的是白底圓框，視覺上更像導覽。
v6小型 chip 切換列 → v7膠囊 Tab（全部 / 生產管理 / 採購與供應鏈）
07
P2
場景卡片改為三欄橫排
從現在的兩欄改為三欄。卡片結構：場景名稱（大字）、分類標籤（兩個）、描述段落、「開始體驗」主按鈕 ＋「前往訂閱」次按鈕。取消左側藍邊情境引言框，改為直接的描述段落。
v6兩欄卡片，含左側藍邊情境引言框 → v7三欄卡片，描述段落 ＋ 雙按鈕

P2

點擊「切換其他職能 ›」後出現一個彈窗，背景模糊，清單列出所有職能（採購、生管、倉管、業務、廠長、物控、產線班組長、IT 資訊、資材、專案經理），當前選中的以品牌色填滿反白顯示。
v6無就地切換職能的機制（需退回 P1） → v7Modal 彈窗，背景模糊，清單可選

v6三段區塊（紅邊痛點 ＋ glass 分身卡 ＋ 引導文） → v7兩個對話氣泡（使用者痛點 ＋ AI 效益）

v6「數智分身已準備就緒」文字 ＋「進入體驗」漸層按鈕 → v7單一深藍大按鈕「開始體驗」
