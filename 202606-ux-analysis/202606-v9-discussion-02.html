改動背景
前提說明
›
兩條並行的修改線
線 A — 需求方串接因應
需求方正進行前後端串接，因版本更新時程來不及，以「不影響串接為前提」調整畫面互動。主要變動：P2 刪除職能視角 Modal（移至 P3 頁面內）、P3 對話內容固定兩則並改為靜態文案、P5 精簡區塊。
線 B — 作品集版本需求
本原型同時作為設計師作品集展示用途。需移除所有企業識別（Logo、企業名稱、雲端圖片資源），確保作品集呈現不帶甲方識別，符合作品集展示規範。
01
P2 / P3 互動流程調整
串接因應
›
P2-1
P2
刪除「開始體驗」後的職能視角確認 Modal
移除 vpModal HTML 區塊、openViewpointModal()、closeViewpointModal()、confirmViewpoint() 及相關 .vp-modal-* CSS。場景卡「開始體驗」按鈕改為直接呼叫 selectScene(s)，不再中途攔截。
P3-1
P3
對話固定兩則，靜態文案
原本 4 則逐條動畫對話改為靜態兩則：使用者說「客戶突然追加 7 倍急單…」、AI 回「AI 職能分身——業務、廠長、採購、GM…」。移除打字動畫（typingBounce）、逐條 setTimeout 邏輯，改為頁面進入後直接渲染。
P3-2
P3
對話框內加備註文字
AI 數智助理對話預覽卡片底部加入備註：「下載專屬分身，就擁有職能戰力。不用從零訓練——開箱就是一整個主管級專家團隊。」以低調小字呈現在卡片內部，對話結束後顯示。
P3-3
P3
加入職能視角選擇區塊（從 P2 移植）
原本在 P2 Modal 的職能選擇，移至 P3 頁面內，位置在「AI 對話預覽」和「分身召集」之間。標題改為「[場景名稱]　你可以選擇的職能」，職能選項以 3 欄 grid 排列，選擇後觸發分身召集動畫。
P3-4
P3
P3 五段式流程動畫串接
各區塊依序以 fadeUp 淡入：① 對話顯示 → ② 備註文字出現 → ③ 職能選擇框淡入（300ms delay）→ ④ 選擇職能後分身召集區淡入 → ⑤ 開始體驗按鈕可用。每段之間有 300–400ms 間隔，強調「階段完成才進下一段」的敘事節奏。

刪減 + Bug 修正
›
P5-1
P5

移除「身為採購，你不再是『打單機器人』……」這段 .p5-ach-sub 區塊，保留頂部成就標題橫幅。
P5-2
P5
「現況突破」Tab 雷達圖上方加標題與說明

P5

P5-5
BUG
右下角 Widget（pgw）顯示修正
問題一：.pgw-card CSS 預設有 animation:pgwSlideIn both，頁面載入時就跑動畫（即使隱藏）。問題二：JS 用 display:'block' 顯示 pgw-group，但 CSS 是 flex，排版錯誤。修正：移除 CSS 預設 animation；JS 一律改用 display:'flex'；三張卡片恢復垂直堆疊 right:24px; bottom:90px。

›
